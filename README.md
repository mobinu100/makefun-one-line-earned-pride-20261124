# One Line of Earned Pride

Entry for [One Line of Earned Pride](https://make.fun/bounty/u-mang-one-line-of-earned-pride-a0138557) on make.fun.

The program writes one quiet, earned line to `/output/entry.txt`:

> After dropping the soup pot twice, eight-year-old Mara carried it across the icy yard with both hands and set it down without spilling a drop.

## Run

```sh
node main.ts
```

`main.ts` is copy-only: it writes the final line (a constant) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). No network, no generation at grade time.
